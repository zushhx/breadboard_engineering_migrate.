# 历史资料

本目录内“当前”“铁律”“通过”“下一版”等表述仅指原文件写作时的条件，不自动成为当前工程状态或操作指令。

- `previous-plans/`：早期需求、v1/v2 目标和施工准备包；其中的目标需要在当前任务中重新确认。
- `legacy-b-route/`：旧 B 路线，保留追溯。
- `report-prompts/`：早期汇报生成提示词，不能作为工程验收来源。
- `workbuddy/`：旧工具的记忆与临时工作，保留本地、不入普通代码提交、不在开工时批量加载。
- [旧固件说明原件](firmware-README.before-engineering.md)：完整保留原文本，其中同时混有旧业务与新增诊断的说明。
- [WSL 安装记录](WSL安装记录_2026-10-12.md)：安装过程与当时环境。

当前入口为[状态页](../STATUS.md)、[任务路线](../ROADMAP.md)和[工程流程](../WORKFLOW.md)。文件原路径映射见 [MIGRATION.json](../MIGRATION.json)；原始日志与旧绝对路径作为历史记录保留。
