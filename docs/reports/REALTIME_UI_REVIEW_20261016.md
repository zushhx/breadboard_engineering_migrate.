## 最终行为与影响

白底、蓝/赭橙/绿三轴图；每轴绘图区220px；约30秒逐轴动态RMS趋势，原始96点详情支持0.5/1/3.6ms。30/60/90秒快捷设置不自动开始。正式资产无场景切换器、模拟数据或设计来源页脚；无外部字体、CDN或前端依赖。用户指定的供电提示条去掉，未验收事实仍保留在工程记录及折叠数据说明。

control::preview在既有记录所有者每块调用点，对全部样本先做整数累积，再执行原预览节流；每5333组逐轴sqrt(E[x²]-E[x]²)，以ug整数发布。近满量程计数沿用±32760轴值门槛，只提示可能受限，不认定机械过载根因。150点固定环形历史、静态HTTP副本和2048字节分块输出；不扩展原Snapshot，不将大数组放主任务/HTTP任务栈。新增静态内存约8KiB，准确资源以对应构建为准。

状态约5Hz、历史约1Hz串行拉取，不重叠；boot/run匹配才接受趋势。新运行/设备重启清空旧图，旧启动令牌禁止控制与接收新会话趋势。暂停冻结图形副本，后台状态和最新数据继续接收，恢复画面显示最新副本。失联保留数据并显示过期；趋势独立失败不锁住停止按钮。无数据、无效INA不伪造零；录制外最后快照有明确标识。

没有改动SDK、CPU、PSRAM、引脚、初始化、采样率、传感器量程、分区、记录文件格式、TF访问顺序或烧录入口。增加记录任务计算负载和网络资源是实质影响，软件测试不能替代实机调度/写入回归。
