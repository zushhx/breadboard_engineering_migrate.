## 适用范围与未测项

本轮通过：当前接法与卡上的基本建文件、写入、同步、关闭、完整重读，以及关闭文件后两次用户确认的全断电重启后数据保留。实际接线沿用用户现场连接，没有仪器测量卡供电瞬态。

未测试写入进行中突然断电、文件系统损坏恢复、持续高负载、真实传感器采集、全卡完整性或长期稳定性。固件恢复未触发，因此恢复试烧本身仍未验收；不能把恢复准备与备份校验称为已实际恢复成功。原 TF 异常的单一根因仍未定位。

后续可在独立方案中继续异常中断与持续负载验证，再接入真实采集。没有合并 main 或发布稳定版。恢复正常只读固件仍按实际授权范围执行，不能用固件恢复回滚 TF 卡内容。
