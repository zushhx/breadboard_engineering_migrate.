1. **旧入口与新基线并存**：原业务 README 含历史上传步骤，且曾混合不同 SDK 状态。原文归档，固件 README 改为明确构建入口；默认 PlatformIO 上传/擦除目标加阻止门槛。旧串口工具仍属硬件操作，不能因路径存在而默认获准运行。

3. **部分暂存漏检**：只校验工作区可能漏过暂存区的冻结文件差异。`4c31137` 增加 Git 暂存区的清单/文件哈希检查。
4. **批准记录空值**：原校验可能把 JSON null 转成非空文字。`4c31137` 改为要求真实非空字符串，并补针对性拒绝测试。该记录是人工流程的辅助检查，不能证明用户身份或代替明确授权。
