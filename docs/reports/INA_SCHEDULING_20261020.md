# INA参考采样节拍修复

2026-10-20，D记录完整性通过，但2082个INA样本中6个无效，发布质量门槛未通过。原始记录及提取证据保留在本轮私人D导出目录；六次发生于8.443429、8.606727、28.818514、129.848168、154.120958、193.613737秒，均早于电脑无线断线。六次config=0x4527、cal=0x0800、mask=0，相邻有效样本mask=8；通信失败会停止并设置错误，本轮errors=0。

[TI INA226数据手册](https://www.ti.com/lit/ds/symlink/ina226.pdf)说明读取Mask/Enable会清除转换完成标志；当前配置16次平均、两路各1.1ms，转换周期35.2ms。原监控任务使用固定绝对节拍，延迟后追赶过期节拍，可能在下一次转换完成前再次读取。完整记录最小相邻间隔15.986ms支持此调度缺陷；尚不能据此声称六次全部根因已由实机修复证明。

修复仅将监控任务改为完成本轮读取后等待100ms，跳过过期节拍。严格有效性判断、配置、优先级、SDK、记录格式及真实时间戳保持。实际参考采样率略低于10Hz，负载延迟时进一步下降。独立审查指出并排除了首稿按读取起点补足周期的缺口：读取内部也可能被抢占，必须从完成后等待。启动前检查及启动快照不会与采集中监控并发读取清标志。

实际模块值宿主检查通过，证据为`local-data/validation/release-v010/ina-module-values-host.log`；另一agent审查最终差异，主agent复核。未为固定延迟新增镜像常量测试。最终候选编译及实机约200秒负载、INA无效为零和完整导出仍是必要回归，软件检查不替代该门槛。设备仍运行D，未刷后续版本。
