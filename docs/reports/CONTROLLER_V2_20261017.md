## 改动与实际边界

- 桌面 .NET Framework4.8/WPF：USB 原生串口、局域网 HTTP 后端复用仅本机 HTTP/WebSocket 转接，检测页和网络设置仍在浏览器；无桌面 TF 页。启动只枚举端口/网络，点击连接才打开串口，不引入烧录入口。
- 主控保留 SDK5.4.2、PlatformIO6.2.0、espressif32@6.11.0、UART0、引脚/时钟/PSRAM/分区/记录格式。USB Serial/JTAG 从副控制台改为专用帧协议；开启 HTTP WebSocket、套接字10→12、URI上限512→1024。实际生成配置由构建清单严格比对；旧已声明的 PHY持久化关闭/断连省电关闭/GDBstub设置保持。宿主编译并发限定2，不改变目标编译参数。
- 四会话所有者租约；原生 PING/PONG 由浏览器网络栈处理，避免仅依赖后台 JS 定时器。退出/刷新/离开释放自己的会话，桌面关闭释放它转接页面的会话；10秒失联发起停止，文件保存/校验完成另计。
- 接管按 observed run/boot/卡身份校验，唯一预约。旧记录安全停止并通过完整回读后才提交新时长、新 run；待接管者失联/取消、旧记录失败和过期条件不启动新记录。停止与开始均无自动重发。
- 独立 NVS命名空间 controller_v2 保存用户明确提交的网络配置，不自动擦除；无凭据或 STA连接失败恢复AP。STA/AP可并用，冲突子网在空闲时选择其他私有AP网段。初次未保存配置前，随机AP密码未跨启动持久化；USB可读取/保存。AP不提供互联网转发。
- TF服务只在主循环执行，借用无采集任务/队列时的固定采集池；文件任务/传输与采集互斥。目录、新建、中文重命名、卡内复制/粘贴、分块上传/下载及确认永久删除。复制/上传临时文件、完整摘要核验再发布，无静默覆盖；失败临时文件保留。路径/根目录/嵌套复制保护，FatFS解析已有父路径阻止长/短名称别名绕过。目录深度8、列表每页16、块2048字节、FAT32单文件4GiB减1字节、传输空闲60秒取消。
- 按用户选择同网络无管理码、具有管理/删除权限；AP使用WPA2密码。网页同源boot令牌、桌面严格Host/Origin/路由限制；密码不写桌面设置/日志。局域网接口不具备独立账号权限隔离。
