# 传感器支路接入：IIS3DWB＋INA226

日期：2026-10-15。方案已选择，**本表不代表实物已接好或功能已验收**。当前事实见 [STATUS](../../STATUS.md)，软件与验收见[本次计划](../../plans/SENSOR_MONITOR_BRINGUP_20261015.md)。

适用此前使用的 IIS3DWB 蓝板＋绿转接板、带 R100 的 INA226 模块。按实物丝印找 IO 和节点，不按排针序号、孔号或线色推断。改线前断开两根 USB、电池等全部电源，确认无供电；不带电移动跳线。

## 本次连接

| 起点 | 终点 | 说明 |
|---|---|---|
| 主控 3V3 | INA226 VCC | 芯片自身供电 |
| 主控 GND | INA226 GND | 可靠共地 |
| 主控 IO16 | INA226 SDA | I2C 数据 |
| 主控 IO17 | INA226 SCL | I2C 时钟 |
| 主控 3V3 | INA226 IN+ | 被测支路进电 |
| INA226 IN− | INA226 VBS | 局部短线，测传感器侧母线电压 |
| INA226 IN− | 绿转接板 VDD | 经 R100 后的传感器供电 |
| 绿转接板 VDD | 绿转接板 VDDIO | 仅在此前同一电源、未另设滤波的接法下板边短接；有分立滤波时先核对，不能盲目跨接 |
| 主控 GND | 绿转接板 GND | 独立可靠共地，不串经松动模块插头 |
| 主控 IO10 | 绿板 CS | SPI 片选 |
| 主控 IO11 | 绿板 SDA | SPI MOSI，**不接 INA SDA** |
| 主控 IO12 | 绿板 SCL | SPI SCK，**不接 INA SCL** |
| 主控 IO13 | 绿板 SDO | SPI MISO |
| 绿板连接座 | 蓝板 J1 | 保留配套 12 芯排线，按原插头缺口方向，不错位 |

INA226 ALERT/ALE、绿板 INT1/INT2/OCS/CSX/SDX/OSDO 本阶段不接。R100 保留、不跨接 IN+ 与 IN−。模块地址跳线保持原状，软件按身份核对实际地址；SDA/SCL 上拉应到 3V3，不能接 5V。

TF VDD 和五个上拉的电源端继续接原主控 3V3，TF 短地线与 CLK38/CMD39/DAT0=40/DAT1=41/DAT2=42/DAT3=47 保留。TF 不接 INA IN−。本次电流只覆盖传感器支路，不是 TF 或整机电流。

## 上电前和功能边界

确认 VBS 不误接 GND；3V3 不误接 5V；同一导通组的孔才可分接，每个插头接适配的一根线；保留传感器板上的去耦与原有滤波。模块若已更换或丝印不同，先核对具体板型，不能套用这张表。

当前主控仍是 TF 诊断程序，接线完成不等于软件能识别新模块；需新模块诊断候选获批试烧后检查。不要以 INA CAL=0 时的零电流解释为传感器不耗电，也不把读到身份寄存器称为电流精度、满速采集或整机验收通过。
