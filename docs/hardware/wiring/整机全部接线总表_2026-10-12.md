# 整机全部接线总表（2026-10-12）

以下直接列出每根连接的两个引脚，适用于 ESP32-S3、INA226、裸 TF 卡转接板、IIS3DWB 绿转接板及蓝传感器板。按优化后的接法整理，实物尚未完成改接与验收。

先断开所有 USB 和其他电源，再改线。IO 编号按主控实物丝印找，不是排针顺序号。

## 1. INA226

| INA226 引脚 | 接到哪里 |
| --- | --- |
| VCC | 主控 3V3 |
| IN+ | 主控 3V3 |
| VBS | INA226 IN−，用局部短线 |
| GND | 主控 GND |
| SDA | 主控 IO16 |
| SCL | 主控 IO17 |

INA226 的 IN− 给下面的 TF 卡、传感器和五个上拉电阻供电，具体逐根列在下表。板上的 R100 保留，不拆焊，不用外部跳线跨接 IN+ 与 IN−。撤掉 IN− 原来接并联测试电阻的负载支路，测试电阻留作复测。

## 2. TF 卡转接板

| TF 卡引脚 | 接到哪里 |
| --- | --- |
| VDD | INA226 IN− |
| VSS | 主控 GND |
| CLK | 主控 IO38 |
| CMD | 主控 IO39 |
| DAT0 | 主控 IO40 |
| DAT1 | 主控 IO41 |
| DAT2 | 主控 IO42 |
| DAT3 | 主控 IO47 |

SD-CD 不接。六根通信线整理成一束短线，给卡片插拔留空间。

### 五个 10 kΩ 上拉电阻

| 电阻 | 一端 | 另一端 |
| --- | --- | --- |
| 上拉电阻 1 | TF CMD | INA226 IN− |
| 上拉电阻 2 | TF DAT0 | INA226 IN− |
| 上拉电阻 3 | TF DAT1 | INA226 IN− |
| 上拉电阻 4 | TF DAT2 | INA226 IN− |
| 上拉电阻 5 | TF DAT3 | INA226 IN− |

上拉电阻接在通信节点的旁支，不串入主控与 TF 的通信线。五个供电端可在卡座附近汇合，通过一根短线连接 INA226 IN−；无需各拉一根长供电线。CLK 不在这五个上拉中。

## 3. 传感器绿转接板

| 绿板引脚 | 接到哪里 |
| --- | --- |
| VDD | INA226 IN− |
| VDDIO | 绿板 VDD，板边短接 |
| GND | 主控 GND |
| CS | 主控 IO10 |
| SDA | 主控 IO11（SPI MOSI） |
| SCL | 主控 IO12（SPI SCK） |
| SDO | 主控 IO13（SPI MISO） |

绿板 SDA、SCL 是本次 SPI 的输入和时钟，不与 INA226 的 SDA、SCL 并接。VDD 和 VDDIO 都要有电；若已加独立滤波支路，保留滤波，不跨过滤波元件短接。

## 4. 配套排线与 USB

| 线 | 两端 |
| --- | --- |
| 配套 12 芯排线 | 绿转接板连接座 ↔ 蓝传感器板 J1 |
| USB 数据线 | 电脑 ↔ 主控此前已验证能烧录和输出串口的 USB 接口 |

排线整条保留，按插头缺口方向插入，不错位。蓝板的供电与通信通过配套排线连接。

## 5. 当前不接或撤去的项目

- INA226：ALE。
- TF：SD-CD。
- 绿板：INT1、INT2、OCS、CSX、SDX、OSDO。
- 并联测试负载电阻及专用负载线，撤出日常装配。
- TF、传感器旧的主控 3V3 直接供电连接，改为从 INA226 IN− 供电；否则会绕过电流测量。
- 外部 IN+ ↔ IN− 短接线不接。模块自带 R100 保留。

## 6. 同一引脚接多根线时

用面包板同一组已确认导通的孔进行分接，或使用合适的分线端子；不往一个杜邦插头里塞多根线。

- 主控 3V3 分接到 INA226 VCC、IN+。
- INA226 IN− 分接到 VBS、TF VDD、绿板 VDD、五个上拉电阻的供电端。
- 主控 GND 分接到 INA226 GND、TF VSS、绿板 GND。

跨面包板需要的连接用短线明确连接。先断电测通断，不按照片孔号或线的颜色猜导通关系。

## 测量范围与验收

此接法测 TF 卡、上拉和传感器的电流，不包含 ESP32、其稳压器损耗或 INA226 自身供电消耗。

断电核对所有端点，再上电量 INA226 IN− 对主控 GND，应接近主控 3V3。依次验证 INA226 识别、TF 短写入和完整读回、传感器身份及静置/移动响应，最后验证真实采集同时显示和写卡。

本表覆盖当前照片中的器件。未确认装配的电池、Qi、电量分压和独立 LED 不作为当前实物接线；主控自带按键不需额外跳线。
