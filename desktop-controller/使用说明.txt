主控控制台 0.1.0

以后直接双击桌面的「主控控制台」，不需要启动 Codex。

日常使用：
1. 给主控供电，保持原来的接线和 TF 卡。
2. 电脑连接主控原先使用的手机热点（2.4 GHz）。
3. 打开主控控制台，点击「打开检测页面」。
   采集开始/停止、时长、三轴曲线、电压、电流、TF 空间和故障提示，
   都在之前的检测页面里操作。

地址变化：
可以点击「查找主控」，选择电脑当前网络，开始查找。
选中找到的设备并点击「使用选中地址」。
较大的网络只查找本机所在 /24 范围；也可以从手机热点的已连接设备列表
查看主控 IP，手动填写并保存。

Wi-Fi 与热点：
软件中的按钮打开 Windows Wi-Fi / 移动热点设置。
当前主控只能连接固件内已有的网络，不能由此软件修改主控的网络凭据。
如由电脑提供热点，名称、密码必须与主控已有配置一致，频段选 2.4 GHz。
软件不会自动创建热点或修改系统网络。

使用一个检测页面即可：
多页面并发轮询有历史采集溢出问题，尚未修复。
关闭本程序或浏览器，不等于停止正在进行的主控采集。
需要提前结束时，在检测页面点击停止，并等待文件关闭和校验完成。

连接检查：
「检测连接」只读取一次主控状态，显示检查时间，不持续轮询。
连接成功不等于传感器精度或完整采集功能已验收。
断线时请核对供电、热点、主控 IP 和热点客户端互访设置。

快捷键：
Ctrl + O   打开检测页面
F5         检测连接

本机文件：
程序在桌面的「主控控制台」文件夹。
设置和滚动连接日志保存在：
%LOCALAPPDATA%\BreadboardController
软件不保存 Wi-Fi 密码或主控 boot 控制令牌，不发送采集命令、不使用串口。

移除：
关闭程序后删除本次创建的「主控控制台」快捷方式和程序文件夹。
按需保留或删除上述 LocalAppData 设置与日志。
不影响主控现有固件、TF 数据和 Windows 网络配置。
