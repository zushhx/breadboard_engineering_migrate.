主控控制台 0.3.0（配套主控 v2 固件）

日常使用：
1. 保持原主控供电、传感器和 TF 接线。
2. 双击桌面“主控控制台”。原生 USB 连接后刷新端口并“连接 USB”；
   或让电脑和主控接入同一网络，填写主控 IP 并“使用此地址”。
3. “打开检测页面”沿用之前的检测页，开始/停止、时长、三轴曲线和状态都在原页。
不需要 Codex。启动软件不会自动采集、打开串口或更改网络。
已有旧控制台连接 USB 时，请在采集停止、保存完成后关闭旧窗口再连接新版。

直接配置主控 Wi-Fi / 热点：
“Wi-Fi 与热点”→“读取主控设置”。
接入 Wi-Fi：扫描附近网络（2.4GHz），选择或填写名称，输入密码，勾选启用 Wi-Fi。
原 Wi-Fi 名称未变时，密码留空表示保留；不会回显原 Wi-Fi 密码。
主控热点：填写名称和8–63字节密码，勾选开启主控热点；可查看当前热点密码。
点击“保存并应用到主控”，稍后重新读取设置，核对实际状态和检测网址。
取消对应开关后保存即可断开 Wi-Fi 或关闭热点；两者可以同时开启。
Wi-Fi 操作可能使连接断开，建议通过 USB 配网。热点不提供互联网。
网址可在控制台复制，其他设备使用 Wi-Fi / 热点地址；127.0.0.1 仅当前电脑可用。
下方 Windows 网络设置仅控制电脑自身，不是主控配网按钮。
Wi-Fi 密码不写入电脑设置或日志。

TF 文件：
控制台左侧“TF 文件”→“读取 / 刷新”。双击或 Enter 进入目录，可手填目录后读取。
支持新建文件夹、中文重命名、TF卡内文件/文件夹复制粘贴、电脑多文件上传、
单文件下载、确认后永久删除。16项一页，点击下一页继续加载。
文件列表支持 Ctrl+C/V；从电脑复制文件后可点击粘贴上传。
本版桌面不上传电脑文件夹；需要时可用原统一网页的“上传文件夹”。
不自动覆盖同名 TF 项目；下载校验长度和 SHA-256 后才保存为最终目标。
删除前显示路径、文件数和大小，需要明确确认；无回收站。
可取消当前文件任务；失败/取消的上传可能保留.partial临时文件，请确认后自行清理。
采集、保存、校验、交接期间主控会拒绝文件操作和网络变更。
网络变更/文件操作只由明确点击发起，结果不明时先刷新，不自动重放。
切换连接清除旧选择和TF复制源，主控重启后需重新读取目录和网络配置。

多页面与退出：
另一页采集中开始会提示继续/取消；继续先安全停止、保存、校验旧记录，再开始新记录。
关闭/刷新/离开采集所属页会请求停采，旁观页面退出不影响所有者。
关闭控制台释放自己转接页面的会话。主控10秒未收到所有者心跳发起安全停止，
排空、保存、校验另计。最小化不主动停止；重新打开不会自动恢复采集。
直接局域网网页由自身会话控制。停止后以主控最终状态为准，不要立即切断供电。

恢复与边界：
旧控制台 v2 保留，可在关闭新版后启动旧版；换桌面程序不会回退固件或删除TF数据。
设置和连接日志位于 %LOCALAPPDATA%\BreadboardController。
本轮不改固件、端口、驱动或主控网络。软件检查与模拟传输通过不能代替真实网络切换、
真实TF写入及断电验收。当前验收范围见工程 docs/STATUS.md。
