数据说明

RMS 由连续约 200 ms 的完整采样窗口计算，逐轴去均值，不等于已标定频带滤波。原始波形不滤波、不去均值。时间按标称 26,667 组/秒估算。

幅值、计量精度及实际切削状态判定尚未验收。供电数据仅为传感器支路。文件通过表示完成本轮设备端回读与摘要比对。
