面包板版相对原 PCB 的 4 条固有差异（不影响"能不能跑"，影响"跑得好不好"）：
① RF 分集链路在面包板上阻抗不可控 → 只验证切换逻辑，不比 RSSI 性能；
② （B 路线做法，当前不复现）10mΩ 采样电阻会被面包板接触电阻（毫欧级）淹没 → INA226 与 R29 必须焊在同一小块板上做四线制。当前 C 路线改用 INA226 成品模块，沿用其自带的 0.1 Ω 分流、不拆换（2026-09-21 决定）；
③ SDMMC 使用 20 MHz 标准档，诊断用 400 kHz；本固件旧 SDK 设置 10 MHz 会停留在 400 kHz；SPI 线尽量 <15cm；
④ SKY13351（1×1mm）与 IP6831（QFN-16）手焊难度高 → 上电测试流程把它们放在最后，焊不动可先跳过，不阻塞其余验证。

五、上电与功能验证流程（三阶段：先备转接板 → 面包板纯插拔 → 洞洞板固化）

阶段 0（准备，唯一需要电烙铁的阶段）：把贴片芯片焊到 SMD→DIP 转接板上。这一步离线一次性做完，可以自己焊、找实验室师兄代焊、或买成品转接板/评估板。此后进入面包板阶段，只插不焊。

阶段 1（面包板验证）：全部 2.54mm 插拔 + 杜邦线。下面 12 步里的"装"= 插上，不焊接。拆改自由。

阶段 2（洞洞板固化，可选）：逻辑跑通后，把转接板和直插件按同一网表焊到洞洞板上，做成能拿去机床现场的抗振动版本。

  1. 静态检查：不上电。通断档确认 GND 轨互通；VBAT/5V/3V3 各轨对 GND 不短路（>100kΩ）。
  2. USB 5V：只装 USB-C 座 + D1（+D2/D3/D4/R4/R5 可后补）。量 5V_VIN ≈ 4.5~4.7V。
  3. 电池链路：装 DW01A、8205A、Q2、SW3、R38/R39、C14。接电池，拨 SW3：VBAT 应=电池电压；拨 OFF 归零。
  4. 3V3_SYS：装 TPS63031 + L1 + C11/C35。空载输出应稳定在 3.18~3.45V。再装 U3/U4（理想二极管 OR），USB 供电时电池路径应被阻断（电池不放电）。
  5. MCU 最小系统：装 WROOM-1U 转接板 + EN/BOOT RC 与按键。USB 连电脑 → 出现串口；烧测试固件点 LED（IO2）。
  6. I²C：装 INA226（+R26/R28/R25）。I2C 扫描应见 0x40；读电流电压与万用表对照。
  7. SPI 传感器：接 IIS3DWB。读 WHO_AM_I(0x0F) 应返回 0x7B（DS12569 Rev 8 默认值 01111011b；0x63 系误记，已更正）；配置 ±16g / FIFO / INT1。
  8. SDMMC：接 SD-NAND。20MHz 标准档挂载 → 写读回测文件；不稳时可用 400kHz 诊断。
  9. RF 分集：接 SKY13351 小板 + 两路天线。IO5/IO6 互斥切换，读两路 RSSI 验证切换逻辑（⚠ 不比性能）。
  10. 充电：装 LGS4056 + NTC 分压（RT1/R40）。插 USB+电池：CHRG_N 低=充电中，DONE 低=充满。
  11. 无线充（最后）：装 IP6831 + 线圈。TX 靠近后 5V_VIN 得电、D1 防倒灌不回灌 USB。
  12. 联调：按原固件状态机（自检→待机 INT1 唤醒→前置判定→采集→流式写卡→收尾→充电监测）跑通 90s 采集落盘。

六、红线与易错点

  • BAT_N（电池负）与 GND（系统 P−）不是同一网络：BAT_N 必须先串过 8205A 才能到 GND。直连=三条保护全部失效。
  • CHRG_N / CHRG_DONE / SD_CMD / SD_D0~D3 / SDA / SCL / ALERT / CS 的上拉一个都不能少，阻值照原网表。
  • IIS3DWB 的 RES 脚（pin2/3）接 VDDIO 或 GND 都可以（DS12569 未强制接 GND，原文表述偏严，已更正）；pin10/11 允许悬空。
  • IO15 是 ADC2 引脚：WiFi 工作时不能当 ADC 用（本设计只做数字中断输入，不受影响）。
  • IO35/36/37 原理图打 NC → 面包板同样不接。
  • U.FL（IPEX1）与 MHF4（IPEX4）严禁互插，模组到板用 IPEX1↔IPEX4 专用跳线。
  • VCTL1/VCTL2 同一时刻只允许一路为高——硬件无互锁，先在固件里保证再上电。
  • R29+INA226 四线开尔文是读数可信的前提；直接插面包板读数会偏差数毫安到数十毫安。

套件里有什么：① 传感器小板（IIS3DWB 精确焊在板中心，带双面胶 + 四角安装孔，对振动测量特别方便，可直接贴到被测件）② STEVAL-MKIGIBV2 适配器板（标准 DIL24 插座兼容，板载 VDD 去耦电容）③ 连接排线。

最容易踩的坑：DIL24 上的 24 个脚是 ST MEMS 适配器标准脚位（VDD / GND / SPC / SDI / SDO / CS / INT1 / INT2 / RES…），不等于 IIS3DWB 芯片的 pin1~14。接线前必须去 st.com 下载该套件的 Schematic PDF，按板上丝印/网络名把 VDD、GND、SPC(→IO12)、SDI(→IO11)、SDO(→IO13)、CS(→IO10)、INT1(→IO9) 找出来再接杜邦。别按芯片脚号猜。

省钱替代：买裸片 IIS3DWBTR（立创 C717702）+ LGA-14 转接板自焊，约几十元，但 0.5mm 间距 LGA 需热风枪 + 锡膏 + 钢网，失败率高——不建议作为首选。

7.3 嘉立创打样拼板的具体步骤

  1. 新建工程（⚠ 千万别在 New Project_2026-09-04_14-48-16 里改，另外新建"转接板拼板"工程）。
  2. 画一块转接板：放置器件封装（立创库搜型号，用现成封装）→ 四周放 2.54mm 排针焊盘（孔径 0.9~1.0mm）→ 逐脚连线 → 加位号丝印 → 底部放 GND 铺铜更好焊。
  3. 复制成多块：每种封装一块，CTRL+C / CTRL+SHIFT+V 按参考点粘贴排布，控制在 10×10cm 以内。
  4. 拼板：顶部菜单 工具 → 拼板 → 选 V 割（到手直接掰开，最省事）或邮票孔（邮票孔直径 0.55mm、间距 0.85mm）；行列间距 ≥1.6mm，工艺边 ≥3mm。
  5. 下单：EDA 里「一键下单」→ 板材 FR-4、板厚 1.6mm、铜厚 1oz、有铅喷锡（好焊）、阻焊默认绿油 → 看有没有免费打样券/学生优惠。
  6. 选 SMT（可选）：上传 BOM + 坐标文件，勾选要贴的器件（芯片需立创商城有货，你现在这颗 BOM 大部分都有 C 编号）。
  7. 到手：沿 V 割掰开 → 焊芯片（QFN/DFN 用热风枪 + 锡膏 + 助焊剂）→ 排针朝下插面包板。
